CredShield MVP

Multi-layer anti-forgery credential network

Inspired by Indian currency-note security: visible trust, cryptographic trust, and authority trust in one credential workflow.

Trust model

1. Visible trust

Credential ID, QR code, issuer name, certificate PDF.

2. Cryptographic trust

SHA-256 hash, Ed25519 signature, chain anchor record.

3. Authority trust

Approved issuer registry, live status, revoke / expiry checks.

Demo flow

  1. Approve an issuer.
  2. Issue a certificate with QR + PDF.
  3. Verify it live.
  4. Edit the payload in the tamper tester and watch validation fail.
